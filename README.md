# Anime.js Counter Animation


> [!NOTE]
> *This project was originally created Apr. 28th, 2024 and was recently updated.*


This is a small proof-of-concept built using:

- [SvelteKit (Svelte 5)](https://svelte.dev/docs/kit/introduction) (Front-end UI)
- [TailwindCSS](https://tailwindcss.com/docs/installation/using-vite) (CSS Styles)
- [Anime.js](https://github.com/juliangarnier/anime) (Animation Library)

> [!WARNING]
> Due to this merely being a proof-of-concept, no support is provided at this time. Updates will come as I deem necessary, but for the foreseeable future, this is how the component will remain.

[Demo](https://animated-counter-sable.vercel.app/)


Purpose:

Animates the main numerical value of the counter, as well as displaying a floating change value indicator, similar to damage indicators in RPG games.
